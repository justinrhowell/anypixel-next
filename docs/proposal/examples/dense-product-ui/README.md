# Dense Product UI — draft pack example

This is a specification example, not an installed extension or a validated design practice. The manifest intentionally retains `UNLICENSED` while the repository's release licensing is unresolved. Publishing under the proposed Apache-2.0 license requires adopting that license and adding its text/notices; the sample does not relicense the existing repository.

Change the Markdown to change the practice. No engine code needs to know what a dense product interface is. The manifest describes the content, its discovery topics, and an optional recommended check. It does not install that check.

The workflow skill can be read directly by a compatible host. Runtime command support is proposed, not available in the current AnyPixel binary. Its relative guide references stay within this pack.

To use this as a future pack template: choose your namespace/owner/license, edit the guide and example, validate the manifest, configure its local directory in your project, and deliberately update the lock. Include evidence before changing the guide's status from experimental to tested.
