# Governance

Justin Howell is the initial project owner. This alpha has not appointed an independent maintainer group. The public roadmap and documented API boundaries guide decisions; design-content ownership can be delegated independently from runtime maintenance.

Ordinary fixes use normal code review. Changes to the public extension API, licensing, or the default practice require a written rationale, compatibility discussion, and test plan. Third-party packs can be distributed and used without acceptance into this repository. Project maintainers do not control the owner's private design choices.

Future maintainers should have a sustained contribution record and a clear responsibility area. Document appointments and any change in decision authority here. Commercial services, if introduced later, must not silently remove documented local capabilities from the open project.
